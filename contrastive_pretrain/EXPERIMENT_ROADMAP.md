## 若信号弱，课题上还能做什么？

信号弱不等于课题不能做，常见转向：

| 方向 | 思路 |
|------|------|
| **更强监督** | 除 PC 外加入可得的临床标签、疾病终点、或中间可预测任务（多任务）。 |
| **换表型定义** | 原始 PC vs 残差 PC、单模态 PC、或只对齐最稳定的几个 PC 维度。 |
| **先学眼底再对齐** |  fundus 上 MAE/SimCLR 等自监督，再小数据对齐 CMR，减轻对 RETFound 通用语义依赖。 |
| **数据层面** | 扩大 UKB 可用样本；或利用公开眼底数据做域预训练再迁移。 |
| **问题重述** | 从「同人检索」改为「表型相似度排序一致性」（与 soft label 一致），降低对 R@k 的依赖。 |
| **融合方式** |  late fusion、双塔 + 浅层交互，而非仅 CLS 单向量。 |

以下实验清单同时覆盖「验证原因」与「尝试改进」。

## Phase 1：标签与预处理（区分「混杂控制」与「可学信号」）

- [ ] **1.1** 对比实验：**残差 PC（已校正年龄性别）** vs **原始 PC** 作为监督目标（或软标签里的 PC），同一模型与评估。
- [ ] **1.2** 同人多条 CMR：明确评估时聚合方式（首条 / 均值 / 随机一条），训练与评估一致。
- [ ] **1.3** 检查 fundus 与 CMR 表 **EID 对齐、重复测量、时间窗** 是否引入噪声（数据质检日志）。

---

## Phase 2：损失与优化目标（与 soft label 对齐）

- [ ] **2.1** 温度 `temperature`、负样本数 `cmr_sample_k` **小网格**（如 temp 0.07 / 0.15 / 0.3 × K 128 / 256 / 512）。
- [ ] **2.2** Soft 模式：`sgt_temp` 锐化/钝化扫描；观察 target 熵与 val Spearman。
- [ ] **2.3** **辅助损失**：在对比损失上加 λ·MSE(预测 PC 或部分 PC)，λ 从很小开始扫（防止压过对比项）。
- [ ] **2.4** 对称 InfoNCE（CMR→fundus）是否稳定 val（若主脚本未开，可对比）。

---

## Phase 3：ViT 微调策略（小数据友好）

- [ ] **3.1** **只训最后 N 个 block**（如 N=4/8）+ 投影头，其余冻结；与全量微调对比。
- [ ] **3.2** **分阶段解冻**：先冻 backbone 若干 epoch，再放开顶层。
- [ ] **3.3** **更小 backbone LR** vs **略大 backbone LR** 各跑一版（配合早停）。
- [ ] **3.4**（可选）**LoRA / Adapter** 只训低秩层，看 val Spearman 是否优于全参微调。
- [ ] **3.5** 强正则：weight decay、DropPath、梯度裁剪已部分使用；记录组合。

---

## Phase 4：数据规模与效率

- [ ] **4.1** 在图像路径齐全前提下，使用 **当前 CSV 能用的最大 fundus 样本量**。
- [ ] **4.2** 若后续 UKB 可扩样：重复 Phase 0.3 学习曲线，判断边际收益。

---

## Phase 5：表征与增强

- [ ] **5.1** 除 CLS 外，试 **patch token 平均池化 / attention pooling** 再投影（需改 `FundusContrastModel.forward`）。
- [ ] **5.2** 训练增强强度：过强可能破坏细粒度信号，试「中等增强」对比。
- [ ] **5.3** 冻结特征 + **仅线性头** 作为强基线；任何微调应明显优于该基线再算有效。

---

## Phase 6：若以上仍无明显提升（结论撰写）

- [ ] **6.1** 汇总：Spearman 是否始终≈0、学习曲线是否平台 → 支持「信号弱或标签噪声主导」。
- [ ] **6.2** 撰写备选方案：多任务、换终点、换模态、或改为「表型排序一致性」为主指标。
- [ ] **6.3** 保留负面结果与超参表，便于论文/答辩说明边界条件。
