# DeepCAD 冠心病眼底图像 AI 筛查系统 — 腾讯云公网部署需求说明

> 供与其他 AI 对接部署时使用的项目概况与需求文档

---

## 一、项目概述

| 项目 | 说明 |
|------|------|
| **名称** | DeepCAD（冠心病眼底图像 AI 筛查系统） |
| **功能** | 用户上传眼底图像，后端通过 ViT-Large 模型预测冠心病风险概率（0～1） |
| **技术栈** | 前端：静态 HTML/CSS/JS；后端：Flask + PyTorch 深度学习推理 |
| **当前状态** | 已在本机/内网可访问，需部署到腾讯云公网 |

## 三、架构说明

- **前端**：纯静态页面（index.html、upload.html），通过 `fetch` 调用后端 API
- **后端**：Flask 提供 REST API，加载 PyTorch ViT-Large 模型做推理
- **端口**：
  - 8000：后端 Flask API
  - 8080：前端静态文件（`python -m http.server` 或 nginx）

**重要**：前端 `app.js` 第 12 行需根据部署环境修改 `API_BASE`，指向公网后端地址。

## 四、环境与资源需求

| 项目 | 要求 |
|------|------|
| Python | 3.8 ~ 3.10 |
| PyTorch | ≥ 1.8（CPU 或 CUDA） |

## 五、部署到腾讯云的核心步骤（供部署 AI 参考）

### 5.1 需要上传到腾讯云服务器的内容

1. **代码与依赖**
   - `web/` 整个目录
   - 项目根目录的 `models_vit.py`、`models_mae.py`
   - `checkpoint-best.pth`（或指定路径的权重文件）

2. **推荐目录结构**
   ```
   /opt/deepcad/  或自定义路径
   ├── models_vit.py
   ├── models_mae.py
   ├── checkpoint-best.pth
   └── web/
       ├── backend.py
       ├── index.html
       ├── upload.html
       ├── app.js
       └── ...
   ```

### 5.2 Python 依赖安装

```bash
pip install flask flask-cors pillow timm==0.3.2 psutil
# CPU 版 PyTorch（无 GPU 时）：
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
# GPU 版根据 CUDA 版本选择对应 torch
```

### 5.3 启动服务

```bash
# 后端（监听 0.0.0.0 以接受外网请求）
python web/backend.py --host 0.0.0.0 --port 8000 --device cpu --checkpoint ./checkpoint-best.pth

# 前端静态服务（开发测试）
cd web && python3 -m http.server 8080
```

**生产环境**：建议用 nginx 托管前端静态文件，并反向代理 `/api/*` 到后端 8000 端口。

### 5.4 修改前端 API 地址

编辑 `web/app.js` 第 12 行：

```javascript
// 改为腾讯云公网 IP 或域名
const API_BASE = 'http://<公网IP或域名>:8000';
```

若使用 nginx 反向代理，可统一为同一域名，如：`const API_BASE = 'https://your-domain.com';`

### 5.5 防火墙与安全组

- 开放 8000（后端）、8080（前端，若直连）或 80/443（nginx）
- 腾讯云控制台需在安全组中放行对应端口

### 5.6 后台持久化

建议使用 systemd、supervisor 或 tmux/nohup 使服务在断开 SSH 后持续运行。

## 六、API 接口（供对接方参考）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/health` | GET | 健康检查，返回 `{"status":"ok","device":"cpu"}` |
| `/api/predict` | POST | 上传眼底图像，返回 `{"probability": 0.xx}` |

预测接口：`multipart/form-data`，字段名 `image`，支持 JPG/PNG/BMP/TIFF/WebP。

---

## 七、需要明确的信息（与运维/部署方确认）

1. **腾讯云实例配置**：CPU/内存、是否有 GPU、操作系统（Ubuntu/CentOS 等）
2. **公网访问方式**：公网 IP 直接访问，还是域名 + nginx + 可选 HTTPS
3. **模型权重位置**：当前训练环境中的权重路径，以及部署服务器上的最终路径
4. **是否需要 HTTPS**：若需 HTTPS，需配置 SSL 证书（如 Let's Encrypt）和 nginx

## 八、快速验证命令

```bash
# 健康检查
curl http://<公网IP>:8000/health

# 预测测试
curl -X POST http://<公网IP>:8000/api/predict -F "image=@/path/to/test.jpg"
```

前端访问：`http://<公网IP>:8080` 或配置后的域名。
